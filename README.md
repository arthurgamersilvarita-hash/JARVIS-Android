# JARVIS Android V1

Projeto inicial funcional para Android.

## Já incluído
- Interface futurista JARVIS
- Núcleo animado
- Reconhecimento de voz em português
- Resposta por voz via TTS do Android
- Estrutura para clima
- Notícias via Google News RSS
- Histórico da conversa durante a sessão
- Abertura do calendário
- Permissões de microfone/localização/notificações

## Como gerar o APK
1. Instale o Android Studio.
2. Abra esta pasta.
3. Aguarde o Gradle Sync.
4. Conecte seu Android ou use um emulador.
5. Clique em Run para testar.
6. Para gerar um APK: Build > Build APK(s).
